어떤 현장에서도
타협하지 않는 현장 보안 체계

고객 데이터는 AI 모델 학습에
사용되지 않습니다.
온프레미스로 배포하면
데이터가 사내를 벗어나지 않습니다.

데이터 암호화

전송 구간은 TLS 1.3, 저장 데이터는
AES-256으로 암호화합니다.
키는 HSM 기반으로 안전하게 분리 관리합니다.

멀티테넌시 격리

조직별 데이터를 완전히 분리합니다.
PostgreSQL RLS와 네트워크 레벨 분리를 통해 교차 접근을 차단합니다.

OT/IT 경계 보안

제조 · 에너지 등 산업 제어 환경

현장 엣지(Silo/Agent)와 클라우드 간 단방향
전송을 지원합니다.
제어 시스템으로의 역방향 침투를 원천
차단합니다.

감사 로그 & RBAC

모든 API 호출과 업무 처리 이력을 안전하게
기록합니다.
역할 기반 접근 제어(RBAC)를 통해 최소 권한
원칙을 적용합니다.

가격은 어떻게 책정되나요?
정책이 확정되는 대로 안내드립니다.
자세한 내용은 영업팀에 문의해 주세요.
도입까지 얼마나 걸리나요?
PoC부터 전사 확장까지 현장 규모와
기존 시스템 복잡도에 따라 달라집니다.
정확한 일정은 상담을 통해 안내드립니다.
보안은 어떻게 보장되나요?
ISO 27001 인증을 보유하고 있습니다.
온프레미스 배포 옵션도 제공하며,
이 경우 데이터가 사내를 벗어나지 않습니다.
현장 데이터를 AI 학습에 사용하나요?
아니오. 고객 데이터는 AI 모델 학습에 사용되지 않습니다.
각 고객의 데이터는 완전히 격리되어 관리됩니다.
기존 SCADA/MES/ERP는 어떻게 되나요?
Refinery는 기존 시스템 위에
통합 지능 레이어로 동작합니다.
기존 시스템과 양방향으로 연동됩니다.
어떤 언어를 지원하나요?
인터페이스와 AI 에이전트의 답변은
현재 한국어로 제공됩니다.
영어 지원은 추후 확대할 예정입니다.
클라우드와 온프레미스 중 선택할 수 있나요?
클라우드, 온프레미스, 하이브리드 모두 지원합니다.
보안 정책에 따라 유연하게 선택 가능합니다.
