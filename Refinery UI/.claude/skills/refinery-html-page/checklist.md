# Refinery 신규 페이지 · 최종 검수 체크리스트

> 모든 항목 통과 시에만 페이지를 사용자에게 인도합니다. 통과 불가 항목이 있으면 임의로 통과 처리하지 않고 사용자에게 명시적으로 보고합니다.

---

## 토큰

- [ ] CSS 안에 hex 리터럴(`#FFFFFF`, `#16202C` 등) 이 컴포넌트 스타일에 직접 박힌 곳이 없다. (예외 — ① 디자인시스템 데모 강제 주입 영역 ② SVG `fill`/`stroke`/`stop-color` 는 §2.2 팔레트·`--dv-*` 와 동일 값에 한해 허용 · CSS `var()` 미해석)
- [ ] 차트 시리즈 카테고리 색은 `var(--dv-1)`→`var(--dv-10)` 순서를 따른다. `style="…"` 안의 색은 토큰만 사용한다.
- [ ] 표면 배경은 `var(--surface-rail|side|topbar|card|page)` 5종 중 하나로만 호출했다.
- [ ] 텍스트 컬러는 `var(--ink-800|700|600|500|400)` 위계를 따른다 — 본문 800, 보조 600, 비활성 400.
- [ ] 브랜드 컬러 `var(--brand|brand-600|brand-700)` 는 액션·강조·데이터 1순위에만 사용했다.
- [ ] 의미 컬러 `var(--good|warn|bad)` 는 상태·정량적 신호에만 사용했다.
- [ ] 폰트는 `var(--font-en|kr|mono)` 만 사용. 입력값·라벨·버튼 텍스트에 Mono 가 들어가 있지 않다.

## 컴포넌트

- [ ] 버튼은 `.rfn-btn` 의 4 변형(Primary / Secondary / Tertiary / Danger) + 3 사이즈(sm 28 / md 32 / lg 40) 안에서만 사용했다.
- [ ] **Primary 외 어떤 변형에도 Refined Blue(`--brand`) 가 들어가지 않는다.**
- [ ] 위젯은 1depth(`.rfn-widget`) + 2depth(`.rfn-box`) 의 두 단계만 사용. 3depth 이상의 중첩이 없다.
- [ ] 2depth(`.rfn-box`) 에 shadow 가 들어 있지 않다.
- [ ] 모든 icon-only 트리거에 `title` 또는 `aria-label` 이 제공된다.
- [ ] 모달 너비는 4단 토큰(`sm 360 / md 480 / lg 640 / xl 800`) 안에서만 사용. 임의 px 너비가 없다.
- [ ] Tab 은 1depth(`.rfn-tabs`, 40h, brand active) / 2depth(`.rfn-tabs--depth-2`, 32h, ink active) 중 하나만 사용. 3depth Tab 중첩이 없다.
- [ ] Toast 안에 액션이 최대 1개. 동시 스택은 최대 4개.
- [ ] Tooltip 안에 액션 텍스트나 클릭 가능한 요소가 없다. `pointer-events: none` 가 유지된다.

## 레이아웃

- [ ] 모든 그리드 행의 span 합이 정확히 16 이다.
- [ ] 페이지별로 추가 breakpoint 를 정의하지 않았다.
- [ ] `.page-head` 의 하단 margin 이 24px 이다.
- [ ] Topbar 에 페이지별 액션이 들어가 있지 않다 — 페이지별 액션은 `.page-head` 또는 위젯 헤더에 있다.
- [ ] App Shell 4영역(Rail / Side / Topbar / Page) 구조가 변경되지 않았다.

## 모드 (라이트 / 다크)

- [ ] `<body class="">` (라이트) 와 `<body class="dark">` (다크) 양쪽에서 페이지가 의도된 색으로 렌더된다.
- [ ] 모드별 분기 CSS(`body.dark .X { ... }`) 가 꼭 필요한 단일 속성에 한해 최소화되어 있다. 토큰 호출만으로 자동 적응되는 컴포넌트가 우선이다.
- [ ] 디자인시스템 데모 컬럼 영역이 있다면 `.ds-mode-col`, `.ds-mode-col.ds-mode-dark`, `.ds-live-canvas`, `.ds-live-canvas--dark` 4종 정해진 클래스만 사용했다.

## 접근성·인터랙션

- [ ] Focus 링이 모든 상호작용 요소에 유지된다 (`outline: none` 만 단독 적용한 곳이 없다).
- [ ] Modal · Popover 의 ESC / 외부 클릭 닫기 동작이 정상이다 (Destructive Confirm 모달 제외).
- [ ] Tooltip 의 `pointer-events: none` 가 유지된다.
- [ ] icon-only 버튼·트리거의 의미가 `title` / `aria-label` 보조 텍스트로 전달된다.

## 단일 소스 link · 컴포넌트 기록

- [ ] `<head>` 에 `<link rel="stylesheet" href="refinery.css">` 가 있고, 페이지에 `<style>` 블록·토큰 hex/px 리터럴이 없다.
- [ ] `bash refinery-verify.sh` 가 exit 0(✅ 통과)이다.
